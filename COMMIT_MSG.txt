Clear the failure alert when the Mac and GitHub agree

The alert file was only removed after a successful push by this script. If the
backlog was cleared another way - a push from GitHub Desktop, say - the script
would find nothing outstanding, exit quietly and leave a stale "did not publish"
warning sitting at the top of the folder. A false alarm that never clears is
worse than no alarm, because it trains you to ignore the real one.

The script now clears the alert whenever it finds this Mac and GitHub in
agreement, however that came about, and records the resolution in .publish.log.

No published page, policy or figure is changed by this commit.
